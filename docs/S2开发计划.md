# MT-EMI 项目 Stage 2 开发计划

2026.10.27 最后一次修订

## 1. 效果器模块

在 `src/mixer` 目录下，开发混音台顶层模块，实现多效果器的混音功能。顶层模块示例如下：

```verilog
module mixer #(
    parameter MAX_POLYPHONY = 32
)(
    input ...,
    input smp_tick_up,
    input signed [15+$clog2(MAX_POLYPHONY):0] audio_in,

    // 混响
    input [15:0] reverb_mix,  // UQ0.16，虽然取不到1但是最接近1的那个值就视为1
    input [15:0] reverb_feedback,  // UQ0.16，反馈系数
    input [15:0] reverb_damping,  // UQ0.16，衰减系数

    // 延迟
    input [15:0] delay_mix,  // UQ0.16
    input [15:0] delay_time,  // 延迟时间，单位为smp_tick
    input [15:0] delay_feedback, // UQ0.16，反馈系数

    // 失真
    input [15:0] distortion_mix,  // UQ0.16
    input [15:0] distortion_gain,  // UQ4.12，增益系数
    input [15:0] distortion_tone,  // UQ0.16，音色系数(亮度)

    // 合唱
    input [15:0] chorus_mix,  // UQ0.16
    input [15:0] chorus_rate,  // UQ2.14，单位为Hz
    input [7:0] chorus_depth,  // 深度，单位为sample_tick数

    // 总增益
    input [15:0] master_volume,  // UQ0.16

    output signed [15:0] audio_out,

    input out_ready,
    input in_valid,
    output out_valid,
    output in_ready,

    input out_ready_lcd,
    output out_valid_lcd
)
```

使用 RAM16SDP 存储音频缓冲。输出的音频采样点需要经过饱和限制处理。

## 2. LCD 屏幕模块

### 2.1. LCD 屏幕驱动模块

这部分写在 `src/drivers/lcd_driver.v` 中，主要负责将一个 RAM 上的数组通过合适的通信协议发送到 LCD 屏幕上进行显示。注意使用 valid ready 信号握手防止 RAM 读写冲突。

RAM核采用RAM16SDP。

### 2.2. LCD UI 绘制模块

这部分写在 `src/lcd_ui/drawers.v` 中，维护 RAM 上的数组，提供画线、画文字（通过 ROM 上载入ASCII 字库）等多个功能。内部具体的模块命名、划分自定，无强制要求。

### 2.3. LCD UI 交互模块

这部分写在 `src/lcd_ui/ui_interaction.v` 中，负责根据 ui 模块提供的事件，进行响应，进而调用绘制方法改变 RAM 数组的内容。

绘制要求：分为主次两部分。主部分负责显示波形或频谱（通过UI事件切换），次部分仅占用屏幕最下方一个大概长条的区域，显示当前正在调整的参数信息。

需要与 mixer 模块进行通信，获取音频采样点并进行缓冲，进而绘制波形或频谱。通信方式为 valid_lcd ready_lcd 信号握手。

## 3. UI 模块

### 3.1. UI 模块的改进

需要添加一些新的输出数据与事件，与 LCD UI 交互模块、mixer 模块进行通信。

### 3.2. 音色保存与读取

实现运用 flash 或 EEPROM 存储音色参数的功能。用户可以通过 UI 模块选择保存当前音色参数到 flash 或 EEPROM 中，也可以读取之前保存的音色参数。实现掉电存储。

这部分可以先在 `src/drivers/` 下实现一个存储器的 Driver，然后再 UI 子模块中调用它。

### 3.3. 和弦与琶音

检测到用户进入和弦或琶音模式后，UI 模块需要将当前的按键自动构建和弦或者琶音，产生新的 note_on/note_off 事件。
