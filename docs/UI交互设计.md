| 操作 | 功能 |

| 触摸一个键 | 触发对应音符 |
| 同时触摸多个键 | 演奏和弦，各键独立控制音量 |

### 1.1 压力与松开判定

| 流程 | 规则 |
| --- | --- |
| 校准压力 | 扣除传感器零点偏差，将压力连续换算为约 0～100%，不划分力度等级 |
| 检测按下 | 当前帧为 1、上一帧为 0，分配声部并发送一次 `note_on` |
| 按住演奏 | 持续读取压力，压力越大，音量越大；最低保持 5% 压力音量，变化经过平滑处理 |
| 检测松开 | 当前帧为 0、上一帧为 1，发送一次 `note_off`，冻结松开时的压力音量 |

每接收一帧完整、有效的键盘数据，计算：

```text
press_event = key_now && !key_prev
release_event = !key_now && key_prev
```

再更新上一帧状态。事件通过“键—声部”对应关系输出；持续按住不重复触发，已被抢占的旧键不能释放新键的声部。Release=0 时直接结束包络并释放声部，不能进行除零计算。

## 2. 旋钮功能、范围、步进与默认值

### 2.1 旋钮模式与参数总表

上电均为模式 0；切换保留参数，不关闭效果。屏幕分别显示各旋钮当前模式、参数名和数值。

顺时针增加，逆时针减少，到边界保持。默认粗调，演奏界面按住 **B4** 时微调，松开恢复粗调。

| 旋钮 | 模式 | 调节参数 | 范围 | 粗调／格 | B4 微调／格 | 默认值 |
| --- | --- | --- | --- | --- | --- | --- |
| K1 | 0 | 左端点波形 | 编号 0～3 | `WAVE_SELECT_STEPS` | 同粗调 | 0，正弦波 |
| K1 | 1 | 右端点波形 | 编号 0～3 | `WAVE_SELECT_STEPS` | 同粗调 | 1，三角波 |
| K2 | 0 | 插值系数 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |
| K2 | 1 | 失谐程度 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |
| K3 | 0,1 | 演奏总增益 | [0, 2) | 约 0.05 | 约 0.01 | 1.0 |
| K4 | 0,1 | 音色平衡增益 | [0, 2) | 约 0.05 | 约 0.01 | 1.0 |
| K5 | 0 | Attack：起音时间 | 1～2000 ms | 10 ms | 1 ms | 5 ms |
| K6 | 0 | Decay：衰减时间 | 1～2000 ms | 10 ms | 1 ms | 150 ms |
| K7 | 0 | Sustain：持续音量 | 0～100% | 5 个百分点 | 1 个百分点 | 70% |
| K8 | 0 | Release：释放时间 | 0～5000 ms | 50 ms | 1 ms | 200 ms |
| K5 | 1 | 混响干湿比 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |
| K6 | 1 | 延迟干湿比 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |
| K7 | 1 | 失真干湿比 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |
| K8 | 1 | 合唱干湿比 | 0～100% | 5 个百分点 | 1 个百分点 | 0% |

K2 模式 1 只调节每声部主音与四路失谐音的混合占比；四路偏移固定为相对基础音约 ±6、±12 音分。0% 时严格只输出基础振荡器的声音，100% 时主音与四路失谐音的总权重各占一半（8:2:2:2:2）。初相固定为 0；失谐合成后维持单声部 16 位采样点与原有复音累加位宽。

K3 控制演奏总音量，不随音色保存；K4 平衡不同音色的响度，随音色保存和读取。两者均为 UQ1.15，默认 `0x8000`（1.0），按压恢复默认。

### 2.2 波表选择与插值

| 波形编号 | 波形 |
| --- | --- |
| 0 | 正弦波 |
| 1 | 三角波 |
| 2 | 锯齿波 |
| 3 | 方波 |

| 项目 | 规则 |
| --- | --- |
| 波形切换刻度 | `WAVE_SELECT_STEPS` 为正整数，累计同方向 XX 格切换一张。屏幕显示波形名称及累计进度 |
| 未满切换刻度 | 保留有符号累计量；反转先抵消累计量，达到正／负阈值后切换一张并清零 |
| 到达波形边界 | 编号 0／3 不再向外切换，并清除朝边界外的累计量 |
| 清除累计量 | 切换 K1 编辑对象、进入／退出菜单、读取音色或恢复默认时清零，避免残留刻度误切换 |
| 插值含义 | 0% 只用左端点，100% 只用右端点，中间值混合两者；相同端点下插值不改变波形 |

开发对应：左、右端点分别输出 `wavetable_0`、`wavetable_1`，当前合法编号为 0～3。插值百分比 p 转成 UQ1.15：`round(p × 32768 / 100)`。

### 2.3 默认值恢复

任何旋钮的按下事件均绑定到当前旋钮的默认值恢复功能。按下旋钮时，当前旋钮的参数立即恢复为默认值，松开旋钮后参数保持不变。

## 3. 弯音轮功能

| 操作／参数 | 功能／数值 |
| --- | --- |
| 调节范围 | −200～+200 音分，即 −2～+2 个半音 |
| 滑动底端 | −200 音分 |
| 滑动中心 | 0 音分 |
| 滑动顶端 | +200 音分 |
| 滑动 | 连续位置映射，无机械步进 |
| 默认值 | 0 音分，不保持上一次触摸位置 |

弯音轮具有回弹的机械结构，能够自动回到中心位置。只需要将中心位置对应的值设为 0 音分即可。

## 4. 主菜单、子菜单与按键操作

### 4.1 进入菜单与选择项目

上电进入演奏界面。按 **B1** 打开主菜单，使用 **B2／B3** 选择项目；主菜单中按 **B4** 返回演奏界面。

| 主菜单项目 | B1 进入后的内容 |
| --- | --- |
| 1 演奏模式 | 回到演奏界面 |
| 2 音色读取 | 用户音色 01～16 槽位列表 |
| 3 音色保存 | 用户音色 01～16 槽位列表 |
| 4 高级音效设置 | 混响、延迟、失真、合唱目录；各音效内部都有恢复默认项 |

演奏界面中，按住 B4 微调，旋钮转动直接生效；按下 B2 切换整个系统的工作模式 0 / 1。

进入高级音效设置时使用模式 2，K1／K2 调节当前效果的两项参数；返回演奏后恢复原模式。普通菜单暂停旋钮编辑，琴键和弯音继续有效。

### 4.2 音色保存与读取流程

| 步骤 | 音色保存 | 音色读取 |
| --- | --- | --- |
| 选择槽位 | B2 上一槽位，B3 下一槽位 | B2 上一槽位，B3 下一槽位 |
| 打开确认框 | B1 打开保存确认框 | B1 打开读取确认框 |
| 确认框内容 | 把当前参数写入选中槽位；已有数据时提示覆盖 | 把选中槽位用于当前演奏；空槽／校验失败不加载 |
| 取消 | B4 取消，返回槽位列表 | B4 取消，返回槽位列表 |
| 执行 | B1 确认执行 | B1 确认执行 |
| 执行结果 | 显示成功／失败提示，B1／B4 返回槽位列表 | 显示成功／失败提示，B1／B4 返回槽位列表 |

执行保存／读取期间等待结果，不重复确认或取消；槽位列表按 B4 返回主菜单。

### 4.3 高级音效设置流程

B2／B3 选择混响、延迟、失真或合唱，B1 进入，B4 返回。

编辑页中，K1／K2 调节两项参数，按压旋钮恢复该项默认值。B2 选择编辑，B3 选择“恢复默认”；在恢复默认项按 B1，重置当前效果的两项参数和干湿比。B4 返回效果列表。

## 6. 音色保存、读取与恢复默认

音色是一套发声参数。保存把当前配置写入非易失槽位，读取把已保存配置应用到当前演奏。槽位显示为“用户音色 01～16”，空槽标注“未保存”。

例如：把“柔和音色”保存到用户音色 01，再调出“明亮音色”保存到用户音色 02。之后读取 01，即可恢复柔和音色的全部保存参数，不必重新逐个调整。

| 功能 | 规则 |
| --- | --- |
| 保存音色 | 选择槽位并确认写入；已有数据时提示覆盖，显示成功后可断电保留。保存内容：左／右端点波形编号、插值、ADSR、失谐程度、四种干湿比、八个高级音效参数、K4 音色平衡增益 |
| 读取音色 | 空槽／校验失败显示错误并保留当前配置；成功时加载保存参数，保留当前总音量和编辑对象 |
| 读取时 | 结束当前声音及效果尾音，再应用配置；仍触摸的键须离开后重新触摸 |
| 读取后修改 | 只修改运行配置，不自动覆盖槽位；再次执行保存才覆盖 |
