# 演示视频分镜

## 1. 开场

展示视频封面、成品展示、基本链路说明

## 2. 基本交互演示

### 2.1. 电容触摸演示

演示手指电容触摸实现选音发声、复音数量、LED 指引

### 2.2. 基本演奏维度演示

1. 演示不同力度的演奏效果
2. 演示弯音轮对音调的变化
3. 演示初相位对音色的变化

### 2.3. UI 基本操作演示

展示 LCD 基本样式，与四个按键的基本功能、旋转编码器的基本操作逻辑。

只需要演示按键对应的模式切换、旋转编码器的参数调节、重置功能与微调功能就行。

### 2.4. 音色切换演示

展示不同音色的切换效果，演示如何通过按键切换音色

### 2.5. 和弦自动弹奏演示

展示和弦自动弹奏的效果，演示如何通过按键切换和弦类型

## 3. 基本功能演示

### 3.1. 波表合成演示

演示波表波形端点的切换、插值系数的调节

### 3.2. ADSR 包络演示

演示 ADSR 包络的调节效果，展示不同参数对音色的影响

### 3.3. 效果器干湿比与增益平衡

演示效果器干湿比与增益平衡的调节效果，展示不同参数对音色的影响

## 4. 高级功能演示

### 4.1. 极限复音量演示

设置为较大 R 值，连续演奏多个音符达到最大复音量但不发生音频卡顿，展示极限复音量的演奏效果。

### 4.2. 高级音效设置

演示对四个效果器的高级设置，展示不同参数对音色的影响。

### 4.3. 音色存储与读取

演示音色的存储与读取功能，展示如何保存当前音色设置并在需要时读取。

## 5. 完整应用演示

演示用户从初始化设备到音色设计、保存与读取、演奏的完整流程，展示设备的易用性和功能丰富性。
