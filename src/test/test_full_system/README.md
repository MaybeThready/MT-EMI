# test_full_system：整机联合测试

本目录沿用 `src/test/<测试名>/{同名.v,.cst,.sdc,README.md}` 的格式，使用根目录 `MT-EMI.gprj`。默认 **24 个触摸键、24 路 FSR、1 个弯音轮、8 个旋钮、4 个 UI 按钮、32 声部**，连接正式 UI、四级 mixer、I2S、LCD 和音色 Flash。琴键按下为高，外接 B1～B4 按下为高；旋钮按下为低。没有自动演奏源。

## 1. 高云软件操作

1. 打开根目录 **`MT-EMI.gprj`**，在 Hierarchy 中选择 **`test_full_system` → Set as Top Module**。新增的两个 `.v` 已列入工程。
2. 禁用工程中所有已启用的 CST、SDC（包括正式 `src/MT-EMI.*` 和旧 `test_ui.*`），仅启用本目录 **`test_full_system.cst`、`test_full_system.sdc`**。一次构建各启用一份。
3. Verilog Standard 选择 SystemVerilog 2017；Include Path 包含 `src`、`src/audio`。运行 Synthesis，再运行 Place & Route。查看 Errors、资源报告、时序报告，不用旧测试的 `.fs`。**本轮已发现时序违例，详见第 6 节；应先修复再进行稳定性验收。**
4. 手动用根工程构建时，下载的是根目录 `impl/pnr/MT-EMI.fs`。优先选择 SRAM 下载，下载后按下并松开 **S0 / K16**。本测试复位低有效。
5. 如需复现本次 CLI 配置，可在 Gowin Tcl Console 执行 `source src/test/test_full_system/build.tcl`（当前目录为工程根目录）。它从根工程生成本地隔离配置，只启用本测试约束，结果为 **`ai_workspace/full_system_build/impl/pnr/test_full_system.fs`**，不覆盖根工程实现结果。脚本可能用时数分钟；必须检查其本轮时序报告。

默认实现采用正式 800×480 LCD 时序。不要把仿真中缩小的扫描视口参数用于实物。

## 2. 接线

沿用 `test_ui` 的键盘、旋钮、按钮、MAX、LCD、Flash 引脚，并追加 `test_velocity` 的 4067 控制线。串行键盘与旋钮各用独立的装载和移位线。下表是信号线；各外设还须供电并共地。

| 功能 | 顶层端口 | 扩展位置 / FPGA 球号 |
| --- | --- | --- |
| 键盘并行装载 | `load_n` | J23.1 / U16，两块键盘共接 |
| 键盘移位时钟 | `key_clk` | J23.3 / U15，两块键盘共接 |
| A 板 12 键串行输出 | `data_a` | J23.5 / W21 |
| B 板 12 键串行输出 | `data_b` | J23.7 / P21；暂不用 B 板时接地 |
| 旋钮板串行输出 Q7 | `knob_serial_data` | J23.2 / V16，接编码器板 J1.7 |
| 旋钮板 PL | `knob_load_n` | J23.4 / V17，接编码器板 J1.3 |
| 旋钮板 CLK | `knob_shift_clk` | J23.6 / Y21，接编码器板 J1.5 |
| B1 / B2 / B3 / B4 | `ui_button[0..3]` | J23.8/U17、J23.9/P23、J23.10/P24、J23.14/R23 |
| 两片 4067 的 S0 / S1 / S2 / S3 | `mux_addr[0..3]` | J23.13/T23、J23.15/R25、J23.17/W23、J23.19/U24 |
| 4067 A 的低有效 EN | `mux_en_a_n` | J23.21 / AC26 |
| 4067 B 的低有效 EN | `mux_en_b_n` | J23.23 / AB25 |
| MAX BCLK | `i2s_bclk` | J26.11 / C21 |
| MAX LRC | `i2s_lrck` | J26.9 / B20 |
| MAX DIN | `i2s_dout` | J26.7 / B19 |
| MAX SD | `sd_mode_n` | J26.5 / A17，高电平选左声道 |

- 数字外设、触摸板、编码器板和模拟前端沿用 **3.3 V** 电源。外接按钮输入下拉，按钮闭合时接 3.3 V。J26.1/2 为 3.3 V，J26.3/4 为地；MAX VIN 沿用先前已经验证的供电接法。
- **4067 A 的 Y0～Y15 → 琴键 P01～P16；4067 B 的 Y0～Y7 → P17～P24**。这是按全局 16+8 分组，不能按两块键盘各 12 路来分组。B 的 Y8～Y15 不使用。
- 两片 4067 的公共模拟输出接同一压力模拟前端；前端处理成 **0～1 V** 后进入 **J3.1/N12（ADCV+）**。**J3.3/P11（ADCV−）接模拟地**。
- 弯音轮经现有缓冲、分压前端处理为 **0 / 0.5 / 1 V** 后进入 **J4.3/R12（ADCT+）**；**J4.1/R11（ADCT−）接模拟地**。J3/J4 的 2、4 脚是 GND。不要把电位器原始 0～3.3 V 直接送进 ADC。
- J3 和 J4 共用一个 `ADCLRC`，顶层使用 `shared_adc_manager` 分时读取。专用模拟脚不声明为数字顶层端口，也不添加 LVCMOS33 约束。
- LCD 接 Dock 的原 J20 排线；Flash 使用板载 U7 的既有连线，完整球号已在 CST 中，不需要飞线。此测试不使用 FPGA 启动 Flash U4 保存音色。

压力默认校准为零点 0、满量程 1690 码、零点死区 8 码；必须结合实际前端校准。`PRESSURE_ZERO_CODES`、`PRESSURE_FULL_CODES` 各包含 24 个 14 位值，最低 14 位对应 P01。弯音轮可用 `BEND_MIN_CODE / CENTER_CODE / MAX_CODE` 校准，方向相反时设置 `BEND_DIRECTION_INVERT=1`。阻值本身不进入 RTL。

## 3. LED 与初次启动

六个 LED 均低电平点亮：

| LED | 含义 | 正常现象 |
| --- | --- | --- |
| LED0 | 音频帧心跳 | 约 1.46 Hz 闪烁 |
| LED1 | 至少一个触摸键按下 | 触摸亮、松开灭 |
| LED2 | 弯音低于中心 | 向低音方向转动时亮 |
| LED3 | 弯音高于中心 | 向高音方向转动时亮 |
| LED4 | 两种 ADC 客户端已有转换结果 | 启动后常亮；不代表模拟接线/电压已经正确 |
| LED5 | 错误锁存：ADC、键盘事件 FIFO、旋钮、UI、音频欠载或 LCD 错误 | 应熄灭；排查后按 S0 清除 |

上电默认普通模式、正弦波、两路增益 1.0、四种音效干湿比 0。先降低外部功放音量；多键叠加和和弦不会自动按音符数衰减。音色存取的成功/失败看 LCD 结果页，不由 LED5 表示。

## 4. 实物验收顺序与预期

每一步记录通过/失败及对应键号，便于把模拟接线、参数配置和音频链问题分开定位。

| 步骤 | 操作 | 应看到/听到 |
| --- | --- | --- |
| 1 启动 | 所有键松开、弯音回中，下载并按 S0 | LCD 正常演奏页，LED0 闪烁，LED4 最终亮，LED5 灭；无持续杂音 |
| 2 24 键映射 | 依次触摸 P01～P24，再松开；特别检查 P12/13、P16/17、P24 | C4～B5 共两个八度，每键一次起音/松音；边界不串键。只有一块板时先测 P01～P12 |
| 3 24 路压力 | 每次只按住一个键，轻压/重压对应 FSR，再改变相邻 FSR | 仅该键音量随对应 FSR 连续变化；零压力仍有约 5% 最低力度；相邻 FSR 不控制它。逐个覆盖全部 24 键 |
| 4 独立多键 | 同按 P01/P05/P08，分别改变三颗 FSR并逐个松开 | C/E/G 独立力度与释放，无卡音。松开后压力音量冻结，尾音由 Release 衰减 |
| 5 弯音联合 | 按住 P10/A4，压力不变，弯音从低端到中心到高端 | 约 G4→A4→B4，连续变音且不重新起音；回中恢复 A4。再边变压力边变弯音，音量与音高各自有效；尾音也可弯音 |
| 6 波形/插值 | 模式0，K1 同向四格换一张波形；K2 改插值；按压恢复 | LCD 波形名称/插值同步变化，声音音色改变。K1 初始左端正弦，K2 默认 0% |
| 7 增益/包络 | K3 总增益，K4 音色平衡，K5～K8 调 Attack/Decay/Sustain/Release；逐个按压 | 听感与 LCD 数值一致，按压恢复当前参数默认值。按住 B4 微调，松开恢复粗调 |
| 8 四音效 | 演奏页按 B2 进入模式1，K5/K6/K7/K8 分别增大混响/延迟/失真/合唱干湿比 | LCD 参数及音效变化；切回模式0保留音效。延迟默认约 250 ms，短音需等待回声 |
| 9 高级设置 | B1 主菜单→B2/B3 选高级音效→B1；逐项进入，K1/K2 编辑；B3选恢复默认、B1执行 | 四种音效的两项参数正确变化；恢复默认同时恢复该效果干湿比等配置；B4 逐级返回，琴键与弯音继续工作 |
| 10 和弦 | B1→演奏模式→B1；B3 选和弦、B1 确认 | 新按一键触发根音/大三度/纯五度，压力控制该键三音；松开释放三音；取消不改变已确认模式，旧按住的音保持原模式 |
| 11 波形/频谱 | 演奏页 B3 切换，持续演奏，调整音量/音色 | 显示从 I2S 实际播放采样得到的波形或频谱；有采集等待时间；屏幕切页/绘图不应造成断音 |
| 12 音色存取 | 使用空闲槽保存已修改音色→再修改→读取该槽 | LCD 显示成功，读取恢复波形、包络、音效及 K4；K3 总增益不随音色读取改变。保存会写用户音色槽，覆盖前先确认槽位 |
| 13 保留/异常 | 断电重上电后读取保存槽；取消确认、读取空槽 | 成功保存的数据保留；取消不写入；空槽/错误读取保留现有参数并显示失败 |
| 14 压力/复位 | 快速重复触摸、多键、旋钮同时调参、菜单中演奏；最后按 S0 | 无卡音、无反复起音、无 LED5 故障；复位立即停声，回普通演奏页与默认参数 |

当前 dev 的范围边界：**读取音色前强制清音、清除效果尾音、无点击声抢占、和弦响度补偿尚未实现**（见 UI 交接说明）；计划中的琶音也未提供现成实现。本测试验证已有实现并保留这些差异，不能据此宣称所有计划功能已经验收。当前读取行为保留原有持续声音；建议松开琴键后读音色。

## 5. ModelSim

当前目录切换到仓库 **`sim`**：

```tcl
do do/test/run_test_full_system_inputs.do
```

先单独检查输入汇合、全部力度字段、同拍更新、随机背压和旋转事件不重复。成功标志为 `TEST_FULL_SYSTEM_INPUTS_PASS`。

```tcl
do do/test/run_test_full_system.do
```

整机自检成功标志为 `TEST_FULL_SYSTEM_PASS`，随后 `$stop` 保留波形。测试从真实 165 串行模型、4067 地址和 ADC 协议模型开始，使用 **32 声部**，检查全部 24 路压力与音高、第二路压力及邻路隔离、5% 下限、弯音不重触发、八旋钮与四按钮、四音效参数交付、和弦菜单、引脚级 Flash 保存/读取、I2S 左声道逐点与实际 PCM 一致/右声道静音、LCD 场景与波形/FFT、复位恢复。

命令行自动退出并返回通过/失败状态：

```text
vsim -c -do "do do/test/run_test_full_system_batch.do"
```

外设专项自动回归入口（包含触摸极性/消抖、24 路压力/FIFO/ADC 故障恢复、按钮、八旋钮、I2S 与弯音校准）：

```tcl
do do/test/run_test_full_system_drivers.do
```

这个入口复用现有 TB 并在完成后自动退出 ModelSim，返回通过/失败状态，不依赖旧压力 DO 的相对工作目录。

首次需本机的 Gowin GW5A 仿真库。可用环境变量 `GOWIN_HOME` 指向本机 Gowin 安装目录或 IDE 目录；亦支持 `GOWIN_PRIM_SIM` 指向其 `prim_sim.v`。提交的 DO 不写入个人安装绝对路径；`modelsim.ini`、日志、库和波形均自动生成到 `ai_workspace/sim`，无需提交。

仿真保留真实 2048 周期采样事件及 ADC 时钟/请求/转换协议，只缩短去抖、Flash 启动、模拟稳定等待和 LCD 扫描视口。图形仍使用正式 800×480 场景。沿用已有同步存储/除法模型；综合始终使用原厂 IP。仿真不代替实测电压、模拟噪声、LCD 排线或扬声器验收；Starter 版会提示设计超过推荐容量，运行较慢。

现有 PLL 的实际输出约 98.245614 MHz，因此实物采样率约 47971.5 Hz；文档的音高、时间按标称 48 kHz 描述。听感/测频比较时允许这约 0.06% 的差异。本次沿用已有 PLL，不改系统时钟模块。

如需深入定位单个模块，可继续运行既有 UI 和弦回归 `do do/ui/run_chord.do`、LCD 回归 `do do/lcd_ui/run_v4.do` 及各驱动单元测试。旧 mixer 的 DO 采用不同工作目录习惯，整机回归已自行编译其正式源码，不依赖那些入口的路径假设。
