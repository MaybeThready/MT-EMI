# test_ui

## 顶层端口与 FPGA 引脚

| 顶层端口 | FPGA 引脚 | 接线 |
| --- | --- | --- |
| `clk_core` | `P16` | 板载 50 MHz 时钟 |
| `rst_n` | `K16` | 低有效复位，沿用旧测试 |
| `ui_button[0]` | `U17`，J23.8 | 外接 B1，按下为高 |
| `ui_button[1]` | `P23`，J23.9 | 外接 B2，按下为高 |
| `ui_button[2]` | `P24`，J23.10 | 外接 B3，按下为高 |
| `ui_button[3]` | `R23`，J23.14 | 外接 B4，按下为高 |
| `data_a`、`data_b` | `W21`、`P21` | 两块键盘板串行输出，沿用旧引脚 |
| `load_n`、`key_clk` | `U16`、`U15` | 键盘板并行装载、移位时钟，沿用旧引脚 |
| `knob_serial_data` | `V16`，J23.2 | 旋钮板 J1.7 / Q7 |
| `knob_load_n` | `V17`，J23.4 | 旋钮板 J1.3 / PL |
| `knob_shift_clk` | `Y21`，J23.6 | 旋钮板 J1.5 / CLK |
| `i2s_bclk`、`i2s_lrck` | `C21`、`B20` | 音频板时钟，沿用旧引脚 |
| `i2s_dout`、`sd_mode_n` | `B19`、`A17` | 音频板数据与使能，沿用旧引脚 |
| `status_led[0:5]` | `J14/R26/L20/M25/N21/N23` | 板载 LED |

旋钮板与四个外接按键使用 **3.3 V**，并与开发板共地。按键输入配置下拉，按下时接 3.3 V。旋钮和键盘的三根扫描线不能共用。LCD 与 Flash 使用 Dock 板现有连线，完整端口约束见 `test_ui.cst`。复位保持 K16，不使用板载 SW5/U4。

## 预期结果

- 琴键按下发声、松开进入包络释放；旋钮 K1～K8 改变 LCD 上对应参数，发声参数随之变化。按下旋钮恢复当前参数默认值。
- B1 打开菜单；B2/B3 选择；B4 返回。演奏页按住 B4 时旋钮微调，按 B2 切换模式。音色保存与读取通过板载 Flash 执行。
- LED0 慢速闪烁表示音频采样持续交付；LED1 常亮表示音频欠载、UI 或 LCD 错误；LED2～4 以低亮权值 1/2/4 显示当前菜单页号；LED5 常亮表示旋钮扫描或队列错误。LED 均低电平点亮。
- 弯音轮暂固定在中心；本测试不检查力度和弯音的物理输入。

在 Gowin 中选择 `test_ui` 为顶层，只启用同目录的 `test_ui.cst` 和 `test_ui.sdc`。更换顶层后重新综合、布线并检查时序。

在 ModelSim GUI 的 `sim` 目录运行 `do do/test/run_test_ui.do`；脚本在 `ai_workspace/test_ui_sim` 建立编译库和波形，成功时显示 `TEST_UI_PASS` 并用 `$stop` 保留波形。
